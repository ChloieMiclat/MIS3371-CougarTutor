# MIS3371-CougarTutor

MIS3371 project repository for **CougarTutor+**, a UH tutoring appointment booking system designed to manage tutoring requests, scheduling, and appointment records.

---

## Project Overview

### CougarTutor+ Tutoring Appointment Booking System

**Project Description: ** CougarTutor+ is a tutoring appointment booking system designed to improve the process of connecting students seeking academic assistance with available tutors. The system provides a centralized platform that organizes tutoring requests and appointment management, replacing informal methods such as emails, sign-up sheets, and word-of-mouth coordination.

**System Purpose:**The purpose of CougarTutor+ is to create a more organized, efficient, and transparent process for managing tutoring appointment requests. The system supports a structured approach for requesting tutoring assistance and coordinating tutoring activities through a centralized platform.

**Project Focus:**CougarTutor+ focuses on improving the tutoring appointment request process by providing a centralized way to submit, manage, and track tutoring requests. The project is centered around creating a reliable system that improves the coordination and organization of tutoring support.

**Project Goal:**The goal of CougarTutor+ is to improve the organization and management of tutoring appointment requests by creating a smoother process for requesting and coordinating academic assistance.
